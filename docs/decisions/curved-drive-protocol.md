# Paired protocol for curved drive and starter tools

The authorized public drive/tractor release advances the shared protocol from10
to11. Curved travel snapshots include a path that older clients do not sample;
the old local prediction would follow the straight chord between server updates.
Older inventory catalogs also do not contain the standalone starter tractor.

Use the existing version-mismatch/reload flow to require the matching browser
and server. Build and promote both public clients and the multiplayer server
from one frozen revision. Player accounts, saved inventories, cargo, SQL schema,
world seed7291 and capacity20 stay unchanged. Rollback restores the paired
application directories; it does not restore or reset the database.
