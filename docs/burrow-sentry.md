# Burrow Sentry

The Sentry is the armed two-seat Burrow variant. Its rear operator pod and twin
laser turret replace the mining storage; the standard mining Burrow remains
available separately. Author gameplay verification is complete; the checked
local integration remains pending.
See [the verification record](qa/burrow-sentry/README.md).

Use Dev → Ship & location → **Burrow Sentry — Selene surface** for a solo test.
The explicit start places you on foot beside the port pilot door. Online, walk
outside your ship and choose **Menu → Ship → Deploy Sentry**; deployment requires
clear supported ground and both door routes. The community hub keeps the armed
vehicle action unavailable under its hands-free policy.

Approach the port door for the pilot, or the aft ladder for the gunner, and press
**controller X / keyboard F**. Wait for the door and boarding movement to finish,
then release the controls. The pilot drives; a second player in the gunner seat
controls the turret. When that seat is empty, the pilot aims and fires it.

| Action | Standard controller | Keyboard |
| --- | --- | --- |
| Drive / reverse / steer | Left stick | W/S and A/D |
| Brake | LT | X |
| Aim turret | Right stick | Arrow keys or mouse |
| Hold twin lasers | RT | T |
| Board / leave stopped rover | X | F |
| Backpack and return | View, then B | I, then Escape |
| Exterior camera | LB + RB, D-pad right | Existing camera controls |

Touch controls appear on the rover panel. The display shows authority, hull and
laser reserve. There is no ore bin in this variant; Backpack opens your ordinary
inventory. Release fire after a seat handover, dialog, focus loss or controller
change. The gunner has priority even while boarding. Brake before leaving.

The geometric cabins are closed, without a pressure simulation. Atlas's real
cargo ramps and deck can carry the taller vehicle; Gannet cannot clear the
moving turret. Vehicles belong to the current session, with no persistent fleet
or purchase economy. Authoritative handheld and Sentry rays can damage the hull;
ship-gun and ship-ram damage against it remain baseline limitations.
