# Burrow Sentry verification

Status: implemented candidate on `feat/burrow-sentry`, private ports 5678/8678.
Not yet browser accepted, integrated or deployed. Parent owns the final checked
source offer and paired protocol-8 refresh of the existing managed preview.

The source preserves checked Transport, Garage and Handheld ancestry through
`f1ef821`. Normal Burrow remains separate. See [player controls](../../burrow-sentry.md),
[the authority decision](../../decisions/sentry-authority.md) and
[source/export provenance](../../../assets/burrow-sentry/README.md).

CPU checks cover physical seat routes and muzzle transforms from the actual GLB;
gunner priority, driver exclusivity and real neutral epochs; owner disconnect,
last exit and wreck cleanup; fixed barrel and incoming rifle damage; all-crew
friendship and held asynchronous membership; hub admission; actual room movement
against walkers/rovers without parked-ship damage; Atlas ramp/frame carry and
Gannet ceiling refusal. Browser evidence is pending and is not inferred from
these fixtures.

Frozen runtime `eda1ba7` passes **42 focused GLB/core/Atlas/security/room cases**
in 19.00 s and production preview build05 in 9.21 s. The earlier **160 registered
normal test files** passed in 39.36 s. The full final multiplayer run needs the
private worktree's generated Prisma client; the exact missing-module finding,
original native runner failures and deck-contact regression are retained in
[the failure record](failures.md). Browser acceptance remains pending.

The portable browser runner hashes all relevant Sentry, shared input/render and
server sources before/after each job, checks actual host process executable and
arguments, uses one Chromium worker with no automatic retry, and writes every
attempt under `test-results/sentry-<timestamp>`. Set `SENTRY_JOURNAL` to the live
shared journal and `SENTRY_TMPDIR` to the lane's short disk-backed directory.
The config starts only its private memory API and production preview.

Required journeys are the physical surface pilot/gunner route with drive,
reverse, aim/fire, backpack/result/return, native focus loss, held modal and
controller disconnect/replacement; a real two-client station/EVA meeting and
both-seat drive/fire/fallback; and keyboard/native 390×844 touch operation.
Injected standard Gamepad and native Chromium touch are reported separately from
physical hardware. Two foreground sessions may use recorded native focus
emulation, with real focus loss exercised separately. Console errors, warnings,
request failures, actual renderer backend and screenshots are retained.

Known scope limits: no persistent rover economy, pressure simulation, hand IK,
Gannet fit, general construction/garage deployment, new authoritative ship-gun
or ship-versus-rover ram damage, or pending Pirate target adapter. Physical
controller hardware, independent art review and performance acceptance remain
separate. No FPS claim is made.
