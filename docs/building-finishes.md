# Building paint and faction prints

For supplied practice, use **Menu → Ship → Open build sandbox**. Return through
**Menu → Ship → Return to regular game**.

On foot outside a ship, open **Build → Finishes**. Select a colour and a print.
Choose a part from Blocks, Shapes, Facilities, Power or Roofs and place it normally.
The preview retains your chosen paint. Prints fit solid walls; large pad emblems
appear when the pad is designated for landing.

To change an existing part, choose **Paint existing parts**, aim at it within12m,
then press **A / Enter / Paint**. This changes only paint and printed decoration;
shape, collisions, storage, door state and power stay intact. Colours cost no
materials. Choose Original mineral and No print to restore an undecorated part.
Only your own parts are paintable, through the existing offline building system.
Saved colours survive reload and use the normal optional solo cloud save.

With a controller, **B** opens Build, **LB/RB** changes tabs, the **D-pad** moves
focus and **A** selects. The sticks aim while painting, a fresh **A** applies once,
**B** returns to Build and **X** exits. **View** opens inventory and **B** returns.
On a phone, the visible Build, Finishes, Paint and Exit buttons provide the route.

These identities are corporate/faction signage; they do not add reputation ranks
or transfer ownership of your builds. Meridian Shipworks, faction posters, helmet
notices and airlock procedure signs are also available in the palette. All prints
are rigid surface signs. Pirate bases use enclosed kit habitats and airlocks;
no tents. Pressure simulation is not added by this appearance feature.
