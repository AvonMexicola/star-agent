# RT fire and controller layout

Cees requests right-trigger ship fire and a graphical controller layout. Scope:
RT/R2 fires, LT/L2 brakes and cancels drive, A/B rises/descends in flight (matching
EVA). Preserve modal A-confirm/B-back, on-foot mining/fire, neutral-input safety,
keyboard and pointer fire. No dependencies, assets, server or save changes.

Add a native dialog reachable through Menu and Help, with a standard controller
silhouette, Xbox/PlayStation equivalents and Flight/On foot/EVA/Shortcuts views.
Use existing mint, white, navy and amber tokens, display/body/mono typography,
central controller with side labels, and stacked phone layout. Validate complete
Nomad/Kestrel patrol journeys, movement/fire independence, held-trigger safety,
keyboard/pointer return, desktop and phone rendering. This is a local development
checkpoint; physical controller and independent visual review remain separate.
