# Cosmic Chicken tenant print sources

COSMIC CHICKEN is the retail promenade's galley tenant. Its two wall prints and
its menu board are runtime textures hung on physical cassettes built by
`blender/build_station_promenade.py`; the artwork is never baked into geometry.

## Provenance

The three masters in `source/` are original artwork generated by the contributor
on 2026-09-10 with ChatGPT, using Imagen 2.5, from a single request covering all
three pieces:

> This is the galley for a game that I'm helping with. This is a generic
> restaurant and I want to make it a spicy chicken restaurant. This is on the
> habitation ring of a space station. Please generate one poster for each wall
> (left and right) for the restaurant. Think silly, punny, but also as you can
> see the style is a bit understated. So we don't want wild colors that will
> clash with the world. Some type of Cosmic chicken brand. Then create an image
> that could be a menu board for the back yellow wall. Use the new imagen 2.5
> software. Two posters and a menu board.

The request was made with a screenshot of the in-game unit as context, which is
why the palette already sits inside the station's petrol, ivory, ochre and mint
language. No third-party brand, stock image, hosted runtime service or downloaded
font is used, and nothing is traced from another game. Per-image seeds and any
further generation settings were not retained by the tool.

## Wordmark repair

Both poster masters carry a damaged wordmark: the **M** of COSMIC was generated
as an A-like glyph, so the supplied posters read **COSAIC CHICKEN**. The menu
master carries the same wordmark, correctly set, in the same typeface, weight and
colour. The runtime derivatives lift that correct word from the menu master and
composite it into the damaged word's own box on each poster, after stretching the
clean row of ground above the line down over it so no flat patch or halo is
introduced. The lockup is justified — COSMIC and CHICKEN share their left and
right edges — so the replacement is drawn to the damaged word's box rather than
its own aspect, costing about four per cent of horizontal width on a geometric
sans. The masters are kept unmodified; the repair exists only in the derivative.

Replacing the masters with correctly spelled artwork would remove the repair
step: set `repair: false` in the build script and rebuild.

## Rebuild

```sh
node scripts/cosmic-chicken-textures.mjs
```

Chromium is used only as an image decoder, canvas and WebP encoder. Nothing is
downloaded, no master is modified in place, and the script is deterministic.

Runtime sizes: wings 819 × 1024 / 83,792 B; sando 819 × 1024 / 72,232 B; menu
1024 × 768 / 79,000 B. All are sRGB and within the repository's 1024² texture
cap. Together they add roughly 235 KB of download and about 13 MB of decoded
texture residency with mipmaps.

## Fiction and gameplay

The board is the tenant's dine-in menu and is decorative. The purchase catalogue
remains `STATION_SHOPS.galley` in `src/station-shop.js`: sealed take-away items
delivered to the station warehouse, with eating, drinking and any survival effect
still unimplemented. Board prices are set dressing and are not a second economy.
